# 🍰 PotCakes Confeitaria - Landing Page

Uma landing page moderna, responsiva e interativa desenvolvida para apresentar a **PotCakes**, uma confeitaria especializada em bolos e sobremesas artesanais.
O foco do projeto foi criar uma experiência agradável para o usuário, destacando os produtos da marca através de um layout moderno, animações suaves e uma navegação intuitiva.
**Status**: O desenvolvimento da estrutura da aplicação foi concluído. O projeto encontra-se em fase de validação com a cliente, podendo receber ajustes pontuais de conteúdo e identidade visual antes da publicação da versão oficial.
